# @declarative-ai/tools

Workspace-backed agent tools - read_file, write_file, edit_file, list_dir, grep, glob, run_command - with a path-escape guard.

The implementations that make a composed prompt executor a coding agent, each guarded against path escape.

```bash
npm i @declarative-ai/tools
```

## Where it sits

Depends on `@declarative-ai/exec`, `@declarative-ai/json`.
It has no dependencies outside the workspace.
