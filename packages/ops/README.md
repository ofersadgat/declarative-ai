# @declarative-ai/ops

The typed operation spine: an operation model generic over a ref family, the function registry, the Signature to JSON Schema bridge, and the metrics floor.

Execution machinery is deliberately absent — ops describes operations, `@declarative-ai/exec` runs them.

```bash
npm i @declarative-ai/ops
```

## Where it sits

Depends on `@declarative-ai/json`.
Outside the workspace: `json-schema-to-ts`.
